A tiny stack virtual machine, written for the
[make.fun competition "Build a tiny stack virtual machine, 22 November 2026"](https://make.fun/bounty/tiny-stack-vm-01-run-20261122).
It runs the competition's 32-bit stack bytecode exactly as specified:
wrapping arithmetic, unsigned division, ten distinct trap codes,
256-word memory, and the step and output limits.
